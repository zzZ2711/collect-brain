# 收藏大脑 · 小红书收藏导出插件

一个 Chrome / Edge 浏览器扩展（Manifest V3），用于把你在小红书网页版「已收藏」的笔记**导出为 JSON**，再一键导入到「收藏大脑」做语义搜索。

> 为什么不直接写进收藏大脑？浏览器的安全策略（跨域）禁止插件跨网站直接写入另一个网站的数据库。因此采用「导出 JSON → 在收藏大脑里点导入」的稳妥方案，隐私更好、最稳。

## 功能
- 自动拦截小红书收藏列表接口，提取笔记（标题 / 正文 / 作者 / 链接 / 封面）；
- 接口抓取失败时，用页面 DOM 兜底抓取当前可见卡片；
- 自动滚动加载「无限滚动」的更多收藏；
- 一键导出 `.json` 并自动打开收藏大脑导入页。

## 安装（开发者模式）
1. 打开浏览器拓展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
2. 右上角打开「**开发者模式**」开关。
3. 点「**加载已解压的扩展程序**」，选择本目录（`extension/`）。
4. 看到「收藏大脑 - 小红书收藏导出」即成功。

## 使用
1. 浏览器打开 `https://www.xiaohongshu.com`，登录后进入 **我 → 收藏** 页面。
2. 等几秒（插件会自动滚动加载更多收藏）。
3. 点浏览器右上角插件图标，弹窗里会显示「已抓取 N 条」。
4. 若数量偏少，点「再抓一次（页面 DOM）」，或手动在小红书页面多滚动一会儿。
5. 点「导出 JSON 并导入收藏大脑」→ 选择保存位置 → 浏览器会自动打开收藏大脑导入页。
6. 在收藏大脑点「**导入 JSON**」→ 选中刚下载的文件 → 等待向量化完成，即可语义搜索。

## 导出 JSON 字段
```json
[
  {
    "note_id": "65f...",
    "title": "笔记标题",
    "note": "笔记正文…",
    "author": "作者昵称",
    "url": "https://www.xiaohongshu.com/explore/...",
    "cover": "https://...",
    "source": "xiaohongshu"
  }
]
```

## 注意事项
- 小红书接口可能随版本调整，若自动拦截失效，依赖 DOM 兜底仍可抓取可见卡片。
- 仅在你**自己的浏览器**上抓取**你自己的收藏**，数据不上传任何第三方服务器（除可选的收藏大脑公有云同步，由你本人主动触发）。
- 本插件与「收藏大脑」主项目配套使用，前端仓库：https://github.com/zzZ2711/collect-brain
